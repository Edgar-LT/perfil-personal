# Perfil Personal - Edgar

Página web de presentación personal diseñada con estética moderna, cálida y editorial.

## 🚀 Características
- **Hero & Avatar**: Presentación cercana y directa.
- **Biografía & Ficha técnica**: Gustos, hobbies (programación, fútbol, gaming) y estilo de vida.
- **Galería Bento**: Mosaico fotográfico responsivo con visor *lightbox*.
- **Rompehielos interactivos**: Temas de conversación y desafíos amistosos (billar, bachata).
- **Buzón de mensajes**: Formulario directo con almacenamiento en LocalStorage y contacto de Instagram.

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3 puro (Flexbox, Grid, variables CSS, backdrop-filter)
- JavaScript Vanilla
